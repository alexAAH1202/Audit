Part 1 · Open decisions (22)

Questions about how the tool behaves. Tick when settled and note the decision.

  1. LEAVE section
    Questions whose clause is still "TBC"
    AS 1670.1 visual alarms, AS 3745 emergency plans and PEEPs, ABCB lift-evacuation guidance and the refuge items have no confirmed clause. The text 'clause TBC' prints in the report until each is resolved.
  2. LEAVE section
    Refuge space of 800 x 1300mm
    A placeholder figure, not confirmed. Give the dimension actually applied, or delete the number.
  3. LEAVE section
    Legislative or Best Practice placement
    Doubtful: the 20N door opening force (fire doors often exceed it) and the WHS written emergency plan (workplaces only). Most of the section is best practice, so Breach of Code should rarely apply.
  4. LEAVE section
    Journey priority of Emergency Information & Alarms
    Set to 4 (information). A missing visual alarm could arguably block leaving, which would make it 1.
  5. Site Scope
    Building class only records, skips nothing
    NCC D4D2 sets the extent of access by class, but the pages are organised by element, so no page is skipped by class. Confirm, or say which classes drop which pages.
  6. Site Scope
    One storey skips Refuge & Assisted Evacuation
    The question counts basements. Mezzanines and raised floors are a risk. NCC D4D4 also lets a small building of up to 3 storeys leave upper levels without a lift.
  7. Site Scope
    No lift marks four lift-only questions not applicable
    Lift landings, lift hearing augmentation, the lift fire-warning sign and lifts as an exit route. Matched by question text. Other questions that merely mention a lift (ramps, stairs, stage platform lifts) are left alone. Confirm the list.
  8. Report
    Finding statements, standard impacts and actions
    None are written in the template yet. Until they are, each finding reads 'Not met:' followed by the requirement, and Impact and Action start empty. Write them per question in the template editor (Report wording).
  9. Report
    Suggested effort for each question
    Every finding starts with a draft effort guessed from the question text: lifts, ramps, toilets, door widths, egress and similar building works are High / capital; signs, information, fittings, management and small adjustments are Low; the rest Moderate. Override per question in the template editor (Report wording, Default effort), or per finding on site and in the report.
  10. Report
    Standard Benchmark and Disclaimer text
    Benchmark is pre-filled with a draft naming the Premises Standards, NCC 2022 Part D4, AS 1428.1, AS/NZS 1428.4.1, AS 1428.2 (best practice) and the DDA. Disclaimer is a placeholder until the firm's own wording is supplied. Both are editable per audit; change the standard text in the template editor.
  11. Capture
    Measured values and their limits
    36 questions that state a figure (widths, heights, gradients, opening force) show a Measured field. The limit is read from the question text, so check it reads right; questions with two dimensions (e.g. 1540 x 2070mm) are left to judgement. The tool only says whether a value meets the figure; the auditor still chooses the answer and severity.
  12. Report
    Draft finding wording made from the requirement
    Until a question has its own wording, the finding statement is the requirement turned negative (e.g. 'Doorways ... do not provide the minimum 850mm clear opening'), the impact is chosen by topic, and the action reads 'Rectify so that <requirement>, in accordance with <clause>'. Read each in the report; replace the common ones with the consultant's own wording in the template editor.
  13. Capture
    Not applicable on every question
    A sixth answer on each question. It counts as resolved in progress and is left out of the score. Confirm the wording, and whether the report should need a reason for each.
  14. Site Scope
    No parking, or attended-only, skips Accessible Car Parking
    Attended-only follows D4D6 (parking service, no public access to spaces). Confirm.
  15. Site Scope
    No sanitary facilities, or shared, skips four pages
    Shared facilities outside the audited area is treated as No. Confirm that is right for a tenancy using a landlord's toilets.
  16. Site Scope
    Build-date follow-up skips the other 2011 toilet page
    My addition to the six questions. Remove it if unwanted.
  17. Site Scope
    Staff only skips nothing
    NCC D4D2(6) covers employees as occupants, so no automatic skip. Confirm whether any page should be left out.
  18. Site Scope
    Acceptance criterion
    The brief says a single-storey building with no lift and no parking skips four pages. With toilets, the template skips three. Restate it or add lift and stairs pages.
  19. Report
    'How to read the ratings' wording
    Written from project terminology, not by the consultant. Confirm each definition.
  20. Report
    No standard disclaimer or liability wording
    Only the template's own Disclaimer field appears. Decide whether standard wording is wanted, with your insurer.
  21. Report
    Timeframes: Do first, Programme, Plan, Monitor
    The mapping from journey priority and effort to timeframe comes from the original patch. Confirm the meaning of each timeframe.
  22. Capture
    Sweep to Pass only on Legislative groups
    The brief names Legislative groups only. Decide whether Best Practice groups should have it too.
